Sistema de Biblioteca. Atividade Avaliativa 02 - Algoritmos e Programação. Sistema desenvolvido em Java para gerenciar livros e usuários de uma biblioteca. Funcionalidades: cadastrar e listar livros, excluir livros, cadastrar e listar usuários, realizar empréstimos de livros, registrar devoluções, verificar a disponibilidade dos livros. Desenvolvido por Gabriel Santana Bernardino.
